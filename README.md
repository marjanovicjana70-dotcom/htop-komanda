## JEDNOSTAVNIJA VERZIJA HTOP KOMANDE 

<h4>Ova komanda je jako slicna htop komandi po tome sto nam daje uvid u kolicinu iskoriscenosti procesora u realnom vremenu. Za svaku nit (ili virtuelni procesor) graficki se prikazuje
njena iskoriscenost u procentima.</h4>

---

Prebaciti ovu skriptu u /usr/local/bin kako bi bila prepoznatljiva sa bilo koje lokacije

```
sudo mv htop-komanda.sh /usr/local/bin
```
